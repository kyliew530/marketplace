# kyliew530 marketplace

A Claude Code plugin marketplace.

## Add this marketplace

```
/plugin marketplace add kyliew530/marketplace
```

## Plugins

| plugin | source | what it does |
| --- | --- | --- |
| `day-trader-skill` | [Jakeschincariol/day-trader-skill](https://github.com/Jakeschincariol/day-trader-skill) (MIT) | 11 day-trading skills: scanner, news, entry/exit timing, Monte Carlo "time machine", risk and budget checks, broker tickets (paper by default), alerts, earnings analyst, congressional trade tracker. |

Install one:

```
/plugin install day-trader-skill@kyliew530-marketplace
```

Plugins listed here are fetched from their upstream repositories, so you get
the author's updates. Not financial advice: read each plugin's own README.
